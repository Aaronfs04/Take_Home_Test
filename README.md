## penggunaan tech stack

frontend:

- react.js
- typescript
- vite => biar efisien create app pakai react.js
- css modules

backend:

- node.js => buat runtime
- express.js => buat ngelola routing sama end point restful API
- CORS => ngehubungin frontend dan backend

database:

- sqlite => database ini karena ringan untuk testing sementara

## buat jalanin backend:

cd backend - npm install - node server.js

## buat jalanin frontend:

npm install - npm run dev
